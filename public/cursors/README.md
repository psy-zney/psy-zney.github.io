# Deep Space Gradient

Original 32 × 32 cursor pair by BLife Team / Custom Cursor, selected by the
site owner from their reference screenshot. Stored locally for cursor loading.

- Source: https://custom-cursor.com/en/collection/gradient/deep-space-gradient
- Arrow: https://cdn.custom-cursor.com/db/25296/32/gradient-deep-space-cursor.png
- Hand: https://cdn.custom-cursor.com/db/25295/32/gradient-deep-space-pointer.png

Hotspots: arrow (1, 1), fingertip (8, 1). Input fields retain the text cursor;
pointer-lock exploration and the existing desktop mouse simulation retain
their input behavior. No browser extension or system cursor installation.
